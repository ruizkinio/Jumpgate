# Brand Assets

The Jumpgate mark, backdrop, and Oxanium font files in this directory are copied
byte-for-byte from the audited Jumpgate Bridge candidate
`0b0d6786673a749ce7f30769b96acef837865fea`.

`jumpgate-social-preview.svg` is the editable 2:1 source for the repository social
card. `jumpgate-social-preview.png` is rendered from that source at `1280x640` using
Chromium with device scale factor 1. Regenerate it after any visual or text change and
visually inspect the exact PNG before use.
